# Guia Turístico da minha cidade

Um guia turístico de Fronteira-MG, a cidade é relativamente pequena (cerca de 17 mil habitantes), mas a cidade é bastante reconhecida pelo turismo.

## Conteúdo
O site aprensenta 3 divisões onde a da esquerda e do meio mostram os locais de turismo que a cidade tem, e a seção da direita possui uma breve descrição da página

Foi utilizado o framework W3CSS que possibilita criar animações, textos, entre outros com facilidade
